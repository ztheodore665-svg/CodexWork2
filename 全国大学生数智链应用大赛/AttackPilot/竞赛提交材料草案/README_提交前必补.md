# AttackPilot 竞赛提交材料草案

本目录依据《区块链大类技术应用赛道说明与提交要求》整理，用于准备 2026 年第三届全国大学生数智链应用大赛技术应用赛道的上传材料。

## 当前结论

AttackPilot 应选择“技术应用—应用实践与应用设计”。它已经具备可运行的链上攻击复盘应用、缓存案例、部署脚本、后端接口、演示视频和项目报告基础，符合“成型的基于区块链的应用系统”方向。

## 提交前必须由团队补齐

- 队长姓名、团队成员、联系电话和指导教师；团队规模应符合 1–5 名学生、1–2 名指导教师的赛事要求。
- 正式作品根目录名：`学校全称-队长姓名-作品名称`。建议：`中山大学-[队长姓名]-AttackPilot`。
- 在线上传地址、访问账号和密码；目前项目只有本地部署地址，没有可直接填写的公网部署链接。
- 作品承诺书：打印草稿后由全体成员手写签名并扫描为 PDF。
- 作品提交日期。
- 演示视频压缩至 50MB 以内，或重新制作不超过 50MB 的演示 PPT。当前视频约 80.75MB，不能原样上传。
- 源代码上传前完成脱敏并重新打包，压缩包总大小控制在 100MB 以内。

## 已从项目确认的内容

- 作品名称：AttackPilot
- 学校：中山大学
- 分类：技术应用—应用实践与应用设计
- 作品形态：面向链上安全事件的攻击复盘 Web 应用
- 本地演示入口：`http://localhost:5173`
- 后端接口文档：`http://localhost:8000/docs`
- 默认依赖：Windows 10/11、Docker Desktop、Node.js 20+、npm 9+，建议内存 16GB 以上
- 可用缓存案例：SushiSwap、ApeCoin 等
- 核心技术：React 18、Vite 5、TypeScript 5、FastAPI、WebSocket、PostgreSQL 15、Redis 7、Docker Compose、JSON-RPC、Etherscan、Tenderly、MCP、OpenAI-compatible LLM API

## 安全注意

原项目 `源代码/backend/settings.py` 中存在硬编码的 Etherscan 和 JSON-RPC 凭据。正式提交前应将其改为环境变量或脱敏占位符，并轮换已经暴露的凭据；提交包不得包含真实密钥。
