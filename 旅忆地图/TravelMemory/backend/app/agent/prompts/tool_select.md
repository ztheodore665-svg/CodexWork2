规则：

1. 只有在问题**需要地图/位置信息才能回答**时才调用工具。涉及用户自己的照片、回忆、
   行程经历的，一律不调用（`tool` 填 `none`）——记忆检索已经能回答，调工具是浪费。
2. 问两地之间怎么走、多远、多久、什么路线 → `calculate_route`。
3. 问某个地方附近有什么、某个景点/设施在哪、门票与营业时间 → `search_poi`。
4. **不确定就填 `none`**。宁可让系统只用记忆回答，也不要乱调工具：
   调错工具的代价是用户拿到一段与问题无关的地名，比"我没查到"更糟。
5. 只输出 JSON，不要解释，格式：

{"tool": "search_poi|calculate_route|none", "reason": "一句话理由"}
