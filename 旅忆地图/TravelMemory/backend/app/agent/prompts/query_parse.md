字段说明：

- **keywords**：核心名词与专有名词，2~6 个，按重要性排序。不要动词，不要停用词
  （"的""了""哪些""什么时候"这类一律不要）。
- **places**：出现的地名，城市名与景区名都算，例如"杭州""乌镇""青海湖"。没有就空数组。
- **themes**：主题词，例如"古镇""博物馆""自然风光""美食""夜景"。没有就空数组。
- **time_range**：形如 {"start":"2025-09-01","end":"2025-11-30"}。
  - 只有**非常确定**时才填，例如"2023 年""去年秋天""上个月"；
  - **拿不准就填 null** —— 时间猜错会直接导致漏召回，比不猜更糟；
  - 农历节日（春节 / 清明 / 端午 / 中秋）一律填 null。

注意：你给出的 `time_range` 只是**候选**，系统里另有一套规则做日历换算，
两者冲突时以规则为准。所以宁可保守。
