## 续跑入口

项目目录：`D:\大三作业\中级实训\旅忆地图+`

Windows PowerShell：

```powershell
Set-Location 'D:\大三作业\中级实训\旅忆地图+'
.\start-dev.bat all
```

Docker Compose（当前可启动数据库与 Redis）：

```bash
sudo docker compose -p travelmemory --profile stage3 up -d --build
sudo docker compose -p travelmemory ps
```

数据库中的演示数据存于 Docker volume `travelmemory_pgdata`；Redis 数据卷为 `travelmemory_redisdata`。不要执行 `docker compose down -v`，否则会删除演示数据。
