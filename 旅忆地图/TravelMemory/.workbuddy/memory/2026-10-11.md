### 关键设计决策（后续阶段沿用）
1. **离线可验证**：没 API Key 时 `LLM_PROVIDER/EMBEDDING_PROVIDER=auto` 自动降级为 mock LLM + 本地哈希向量，整条管道可无 Docker/无密钥跑通；`VectorSearchPort` 抽象让单测用内存检索替代 pgvector。

4. **Prompt 版本化**：PROMPT_VERSION = `pv2026.10-stage0.1`，改 prompt 必须同步递增。
5. demo 语料 ID 与评测集对齐（t1=2025 秋江南古镇、t2=杭州、t3=2024 五一洛阳、p12=西湖）。
