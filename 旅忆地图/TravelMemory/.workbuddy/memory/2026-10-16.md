## 阶段 0 Windows 实战交接后的修复（按用户给的行动清单）

用户在 Windows 11 + PowerShell + Docker Desktop(WSL2) 上真实跑通了阶段 0，并给出交接文档。据此做的修改：

1. `backend/docker/db/Dockerfile`：**基础镜像从 `postgis/postgis:16-3.4` 换成 `pgvector/pgvector:pg16` + apt 装 `postgresql-16-postgis-3`**。原因：前者基于 Debian 11(bullseye)，其 PostgreSQL 官方源已 404，装不到 pgvector（连 server-dev 头文件都没有，源码编译失败）。已在 Dockerfile 里写清原因注释。
2. `backend/alembic.ini`：**改为纯 ASCII（UTF-8 无 BOM）**。Alembic 用 `encoding="locale"` 读 ini，中文 Windows locale=GBK，含中文即 `UnicodeDecodeError`。比用户"转成 GBK"更彻底。
3. `docker-compose.yml`：db 保持 `build: ./backend/docker/db`，加 BOM 警告注释（带 BOM 时 Docker 报 invalid trailing UTF-8 octet）。
4. `app/db/checks.py`：向量模型不一致时，额外提示离线模式该改的四个变量。
5. `app/cli.py`：①占位模式且 `RETRIEVAL_MIN_SCORE>=0.2` 时主动提醒改 0.05；②捕获 `KeyboardInterrupt/CancelledError`，Ctrl+C 退出不再抛噪音；③`dispose_engine` 包 try/except。
6. `.env.example` / `README.md`：新增「Windows 环境注意事项」章节（无 make 的等价命令对照表、镜像/加速器、alembic 编码、离线模式阈值、exit 退出）。
7. `docs/stages/stage0-rag-cli.md`：新增第 10 节「Windows 实战记录」（环境差异、镜像方案替换原理、实测指标、出口条件达成表、因此永久改了什么），易错点扩到 14 条。
8. `tests/test_document_service.py`：新增 `_column_dim()` 从库里读真实向量维度（conftest 把 EMBEDDING_DIM 改成 256，与真实库 1024 冲突会 DataError）。

### 关键决策
1. **幂等键 = (photo_id, job_type, ai_model)**：ai_model 进键，换模型即触发重跑且旧结果保留可对比；force 才重置 done。
2. **W1-3 只做"天"聚合**（Trip 表属阶段 6 W6-2），留 TripGrouper 的口子，Document 结构不变。
3. index_job 里用 `_built_days` 去重，避免同一天的 embedding 被重复烧 N 遍。
4. **修正 Document 唯一键加入 user_id**（迁移 0003）：原三元组会让两个用户的 day/同一天#0 互相覆盖（测试暴露的真 bug）。偏离设计文档 §4.1 的三元组定义，已在两份 stage 文档里写明原因。
