# 第一次作业：图像插值实验报告

## 1. 实验目的

使用 Java 实现最近邻插值、双线性插值和双三次插值，并将三种方法用于同一张实际图片的 0.5 倍缩放和 3 倍缩放，观察不同插值方法对图像清晰度、边缘和细节的影响。

## 2. 实验环境

- 操作系统：Windows
- 编程语言：Java
- JDK：17 或更高版本
- 依赖：Java 标准库 `java.awt.image.BufferedImage`、`javax.imageio.ImageIO`

## 3. 算法原理

### 3.1 最近邻插值

将目标像素映射到输入图像连续坐标后，取距离最近的整数坐标像素：

`f(x,y) = f(round(x), round(y))`

该方法计算量最小，但会产生明显的锯齿、块状边缘和阶梯现象。

### 3.2 双线性插值

使用目标坐标周围的 2×2 个像素，先沿 x 方向线性插值，再沿 y 方向线性插值：

`f(x,y) = (1-a)(1-b)f00 + a(1-b)f10 + (1-a)b f01 + ab f11`

其中 `a`、`b` 是小数坐标。该方法比最近邻平滑，计算量适中。

### 3.3 双三次插值

使用目标坐标周围的 4×4 个像素，并使用 Catmull-Rom 三次卷积核计算权重：

`f(x,y) = ΣΣ f(i,j) w(x-i) w(y-j)`

相较双线性，双三次能利用更大的邻域恢复更连续的边缘和纹理，放大结果通常更自然，但计算量更大，并可能在强边缘附近产生轻微过冲。本项目对最终通道值进行了 0 到 255 的钳位。

## 4. 实验步骤

1. 读取 `input/sample.png`。
2. 将每个输出像素映射到输入图像的连续坐标。
3. 分别使用三种算法生成 0.5 倍和 3 倍图像。
4. 将结果以 PNG 格式写入 `results/`，便于无损比较。

批量处理 `src` 文件夹中的全部图片时，执行：

```powershell
.\batch.ps1
```

批量结果写入 `results-src/<算法>/<倍率>/`，每张输入图片对应一个同名 PNG 文件。

运行命令：

```powershell
.\run.ps1 -InputImage ".\input\sample.png"
```

## 5. 结果文件

| 方法 | 0.5 倍缩放 | 3 倍缩放 |
|---|---|---|
| 最近邻 | `results/nearest_0.5x.png` | `results/nearest_3x.png` |
| 双线性 | `results/bilinear_0.5x.png` | `results/bilinear_3x.png` |
| 双三次 | `results/bicubic_0.5x.png` | `results/bicubic_3x.png` |

实际运行时，程序会根据输入图片的原始尺寸计算输出尺寸：`round(原宽 × 倍率)` 和 `round(原高 × 倍率)`，最小尺寸限制为 1 像素。

## 6. 现象分析

- **0.5 倍缩小**：最近邻容易丢失细线和小文字，并可能产生不连续的边缘；双线性会使细节变柔和；双三次通常能较好地保持轮廓过渡，但极细高对比度结构仍可能因采样而损失。
- **3 倍放大**：最近邻会出现明显的马赛克块；双线性边缘较平滑，但细节偏软；双三次的边缘和纹理过渡更自然，主观清晰度通常最高，同时需要注意高对比度边缘附近的轻微振铃。
- **速度**：最近邻只读取 1 个像素，速度最快；双线性读取 4 个像素；双三次读取 16 个像素，计算量约为双线性的 4 倍，适合更重视视觉质量的场景。

## 7. 结论

三种算法均可用于实际图片缩放。若要求速度和像素风格，选择最近邻；若需要速度与质量平衡，选择双线性；若更重视放大后的边缘和纹理质量，选择双三次。程序已将输入、输出目录、缩放倍率和算法列表参数化，可以直接替换 `input/sample.png` 为任意实际图片重新实验。
