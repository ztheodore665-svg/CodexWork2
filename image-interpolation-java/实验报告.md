## 摘要

本实验使用 Java 实现了最近邻插值、双线性插值和双三次插值三种图像缩放算法，并将算法应用于 `src` 文件夹中的 19 张实际图片。每张图片分别缩小到原尺寸的 0.5 倍、放大到原尺寸的 3 倍，最终生成 114 张 PNG 结果图。实验结果表明：最近邻插值计算量小但容易产生明显的块状边缘；双线性插值具有较好的平滑性和适中的计算量；双三次插值使用更大的像素邻域，放大结果通常更自然，但计算时间最长。

**关键词：** 图像插值；最近邻插值；双线性插值；双三次插值；Java；图像缩放

## 1. 实验目的

1. 理解图像缩放中连续坐标与离散像素坐标之间的映射关系。
2. 掌握最近邻、双线性和双三次插值的基本原理。
3. 使用 Java 独立实现三种插值算法，不调用现成的图像缩放函数。
4. 对实际图片进行 0.5 倍缩小和 3 倍放大，并比较不同算法的视觉效果和计算代价。

## 3. 坐标映射

设输入图像尺寸为 `W_in × H_in`，输出图像尺寸为 `W_out × H_out`。本实验采用边界对齐的坐标映射：

```text
x = x_out × (W_in - 1) / (W_out - 1)
y = y_out × (H_in - 1) / (H_out - 1)
```

其中 `(x, y)` 是输出像素对应的输入图像连续坐标，`(x_out, y_out)` 是输出图像中的整数坐标。该映射保证输出图像的四个边界与输入图像边界对齐。对于超出图像边界的采样坐标，程序采用边界钳位策略，将坐标限制在合法范围内。

## 4. 三种插值算法原理

### 4.1 最近邻插值

最近邻插值直接选择距离目标连续坐标最近的输入像素：

```text
f(x, y) = f(round(x), round(y))
```

该方法只需要访问 1 个像素，速度快、实现简单，但放大后容易出现马赛克、锯齿和阶梯状边缘。它适合像素画、标签图或对速度要求较高的场景。

### 4.2 双线性插值

双线性插值使用目标坐标周围的 2×2 个像素。令 `x0=floor(x)`、`y0=floor(y)`，`a=x-x0`、`b=y-y0`，则：

```text
f(x,y) = (1-a)(1-b)f(x0,y0)
       + a(1-b)f(x0+1,y0)
       + (1-a)b f(x0,y0+1)
       + ab f(x0+1,y0+1)
```

双线性插值相当于对水平和垂直方向分别进行一次线性插值。与最近邻相比，它可以有效减弱锯齿，但会使细节略微变柔和。

### 4.3 双三次插值

双三次插值使用目标坐标周围的 4×4 像素，并用三次卷积核计算权重：

```text
f(x,y) = Σ(i=-1..2) Σ(j=-1..2)
         f(x0+i,y0+j) w(i-dx) w(j-dy)
```

本实验使用参数 `a=-0.5` 的 Catmull-Rom 三次核：

```text
w(t) = 1.5|t|³ - 2.5|t|² + 1,             0 ≤ |t| ≤ 1
w(t) = -0.5|t|³ + 2.5|t|² - 4|t| + 2,     1 < |t| < 2
w(t) = 0,                                  |t| ≥ 2
```

双三次插值使用的邻域更大，通常能得到更自然的轮廓和纹理。但由于计算 16 个邻域像素的加权和，计算量明显高于前两种方法。插值后，程序将每个颜色通道限制在 `[0,255]` 范围内，防止三次核在强边缘处产生越界颜色。

## 5. Java 程序设计

项目结构如下：

```text
image-interpolation-java/
├─ src/
│  ├─ ImageInterpolator.java       三种插值算法核心实现
│  ├─ InterpolationMethod.java     插值方法枚举
│  ├─ Main.java                    单张图片处理入口
│  ├─ BatchMain.java               文件夹批处理入口
│  └─ InterpolationTest.java       基础正确性测试
├─ input/                          单张图片示例
├─ results/                        单张图片结果
├─ results-src/                    src 文件夹批处理结果
├─ run.ps1                         单张图片运行脚本
└─ batch.ps1                       批处理运行脚本
```

核心方法为：

```java
BufferedImage resize(BufferedImage source,
                     int targetWidth,
                     int targetHeight,
                     InterpolationMethod method)
```

该方法统一完成输出尺寸创建、坐标映射、算法选择和像素写入。`BatchMain` 遍历 `src` 文件夹中的图片，并按算法和倍率生成目录：

```text
results-src/<算法>/<倍率>/<原文件名>.png
```

例如：

```text
results-src/bicubic/3x/cameraman.png
```

## 6. 实验步骤

1. 将待处理图片放入 `src` 文件夹。
2. 在项目目录执行批处理脚本：

4. 对每种算法生成 0.5 倍和 3 倍结果。


## 7. 实验结果

### 7.1 结果数量与尺寸

本次实验共处理 19 张图片，每张图片输出：

- 最近邻插值：0.5 倍、3 倍各 1 张；
- 双线性插值：0.5 倍、3 倍各 1 张；
- 双三次插值：0.5 倍、3 倍各 1 张。

因此总结果数为：

```text
19 × 3 × 2 = 114 张
```

例如，`cameraman.tif` 原图为 512×512，输出尺寸为：

| 插值方法 | 0.5 倍结果 | 3 倍结果 |
|---|---:|---:|
| 最近邻 | 256×256 | 1536×1536 |
| 双线性 | 256×256 | 1536×1536 |
| 双三次 | 256×256 | 1536×1536 |

对于 256×256 的输入图像，程序相应生成 128×128 和 768×768 的结果。

### 7.2 代表性运行时间

下面是 `cameraman.tif` 在本机上的一次运行记录，时间会受到处理器、JVM 即时编译和磁盘写入速度影响，仅用于展示相对趋势：

| 方法 | 0.5 倍 | 3 倍 |
|---|---:|---:|
| 最近邻 | 27.6 ms | 127.5 ms |
| 双线性 | 17.0 ms | 278.6 ms |
| 双三次 | 68.6 ms | 1490.4 ms |

对于大多数图片，双三次的运行时间明显高于最近邻和双线性，这是因为每个输出像素都需要访问 4×4 邻域并计算三次核权重。

### 7.3 视觉效果分析

**缩小到 0.5 倍：**

- 最近邻保留了部分原始像素，但细线、小文字和高频纹理容易出现跳变或丢失。
- 双线性结果更平滑，锯齿减弱，但细节会有一定程度的模糊。
- 双三次对边缘过渡的保持较好，整体观感通常优于双线性，但无法完全恢复缩小过程中已经被采样丢失的细节。

**放大到 3 倍：**

- 最近邻产生明显的像素块，边缘呈阶梯状。
- 双线性消除了大部分块状结构，结果比较平滑，但轮廓会偏软。
- 双三次生成的边缘连续性和纹理过渡更好，主观清晰度通常最高；在黑白强边缘附近可能出现轻微过冲或振铃。

## 9. 问题与改进

1. 最近邻插值速度快，但视觉质量最低；实际应用中应根据图像类型选择算法。
2. 双线性插值在放大文字和细线时可能偏模糊，可以结合锐化滤波改善观感。
3. 双三次插值计算量较大，可以预先缓存每一列和每一行的坐标、索引和权重，以进一步提高处理速度。
4. 当前程序使用边界钳位处理图像边缘；也可以尝试镜像边界或周期边界，比较不同边界策略的影响。
5. 当前程序主要针对 8 位通道图像，后续可以扩展到 16 位灰度图和带透明通道的图像。

## 10. 结论

本实验使用 Java 完成了最近邻、双线性和双三次三种图像插值算法，并成功应用于 19 张实际图片的 0.5 倍缩小和 3 倍放大。实验结果与三种算法的理论特点一致：最近邻速度最快但容易产生块状伪影；双线性在速度和质量之间取得平衡；双三次的边缘和纹理表现较好，但计算代价最高。

综合考虑，像素风格图像或实时处理可以选择最近邻；一般图像缩放可以选择双线性；对放大质量要求较高且能够接受较长处理时间时，推荐使用双三次插值。
