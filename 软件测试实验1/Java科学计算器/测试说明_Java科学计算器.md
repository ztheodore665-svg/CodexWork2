# Java 科学计算器测试用例

完整测试用例见同目录的 `测试用例_Java科学计算器.csv`，CSV 首行为固定字段：

`用例ID, 模块, 功能点, 前置条件, 操作步骤, 预期结果, 测试类型, 优先级, 严重等级`

共 62 条：功能测试 25 条、异常场景 12 条、边界值 6 条、安全校验 4 条、兼容性 4 条、UI 4 条、易用性 4 条、并发 2 条、弱网 1 条。优先级为 P0 14 条、P1 42 条、P2 6 条。

## 测试重点风险点

1. 表达式解析：括号不匹配、连续运算符、未知函数、特殊字符、代码注入、超长表达式可能导致错误结果、卡死或异常退出。
2. 数值边界：除零、负数开方、非正数对数、负数/非整数阶乘、极大/极小值及 Infinity/NaN 展示。
3. 输入状态：AC、CE、退格、计算完成后继续运算、重复点击等号/函数/运算符之间的状态串扰。
4. 精度与格式：三角函数角度/弧度模式、π/e 常数、小数舍入、科学计数法及整数格式化。
5. 安全性：解析器必须只允许白名单数学语法，不得执行 Java 方法、访问文件或暴露堆栈和路径信息。
6. 桌面兼容性：Java 8/25、Windows 高 DPI、系统外观、字体、窗口固定尺寸和按钮可见性。
7. 适用性边界：本版本为纯本地 Swing 程序，没有账号、服务器、表单提交或网络依赖；服务器 500/超时和权限越权用例用于确认不存在隐藏依赖。

## 简易测试执行注意事项

1. P0 用例先执行；任一 P0 失败时暂停回归并记录截图、输入序列、Java 版本和操作系统。
2. UI 用例使用实际打包的 `calculator.jar` 和源码编译包各执行一次；数字结果同时记录显示值和历史表达式。
3. 科学函数先核对底部模式指示器，再执行输入；角度模式使用 30/45/60/90 等可人工校验数据。
4. 异常用例每条触发后先确认程序仍存活，再点击 AC 验证恢复，不要直接重启替代恢复性验证。
5. 超长输入、并发点击和 100 次重复计算需记录最大响应时间、CPU/内存异常及是否出现无响应。
6. 安全校验的非法表达式建议通过独立 Java 测试驱动调用 `evaluateExpression`；禁止在真实环境执行可能修改系统的 payload。
7. 断网、代理超时等网络用例只验证本地应用无网络依赖，不要把模拟 HTTP 结果当成产品实际接口功能。
