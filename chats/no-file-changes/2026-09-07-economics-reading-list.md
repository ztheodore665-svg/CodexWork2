# 经济学入门学习书目推荐

日期：2026-09-07
分类：无文件改动 / 纯问答聊天

## 用户问题

经济学入门学习推荐什么书目，我已经读完《小岛经济学》，现在正在阅读《薛兆丰经济学讲义》。

## 回答整理

当前阅读路径《小岛经济学》→《薛兆丰经济学讲义》适合作为经济学直觉的入门。后续建议逐步从通俗读物进入正规的微观、宏观经济学框架。

推荐路线：

1. 《小岛经济学》——已读
2. 《薛兆丰经济学讲义》——在读
3. 《牛奶可乐经济学》——继续训练生活中的经济学直觉
4. 曼昆《经济学原理：微观经济学分册》——系统建立微观经济学框架
5. 曼昆《经济学原理：宏观经济学分册》——学习 GDP、增长、通胀、失业、货币、利率、财政和货币政策等
6. 《置身事内》——理解中国政府、地方财政、土地财政、城市化、债务和房地产
7. 《魔鬼经济学》——训练因果关系、激励与数据分析思维
8. 《贫穷的本质》——进入发展经济学和实证研究
9. 《为什么国家会失败》——理解制度、产权、政治权力与长期经济发展

其他可选读物包括《卧底经济学》《思考，快与慢》《激荡三十年》《大空头》等。

对于软件工程背景，完成经济学原理后可以进一步沿“概率统计 → 计量经济学 → 金融学”方向学习，把编程和数据分析能力与经济学结合。
